# musik для iOS (SwiftUI)

Нативный клиент Go player (`:8787`) для iPhone/iPad. Тот же API и тот же
playback-протокол, что у веба и Flutter-клиента: `radio/start` | `play` |
`mixes/{kind}/play` → stream → `track_start` → `progress` (~4 с) →
`track_end` | `skip` → `next`. См. [docs/API.md](../docs/API.md) и
[docs/MOBILE.md](../docs/MOBILE.md).

## Что умеет

- **Вход**: адрес сервера + `MUSIK_API_TOKEN` (Keychain, Bearer) или пароль (cookie).
  401 возвращает на экран входа.
- **Главная**: ▶ Радио, «Поделиться» (share radio), «Обновить миксы» (job
  `mix_pack` с опросом), полки «Для тебя», «Дни недели», любимые
  песни/артисты/альбомы, «Похожее на любимое», «Открытия», «Давно не звучало»,
  артисты, альбомы, треки.
- **Библиотека**: треки / артисты / альбомы / любимое + поиск; тап по треку играет
  видимый список с этого места; долгое нажатие — меню (радио от трека, «Потом», ♥,
  весь артист / альбом).
- **Артист / альбом**: играть всё, радио, ♥, треки, похожие артисты / альбомы.
- **Плеер**: обложка, перемотка, назад / пауза / дальше, ♥ (+ like), дизлайк,
  «Потом», «Похожее», ♥ артист / альбом, радио от трека, очередь радио с
  объяснением «почему», полный список с прыжком, текст песни (LRC подсвечивается).
- **Мини-плеер** на всех вкладках, **фоновое воспроизведение**, экран блокировки,
  кнопки наушников и Пункта управления (play / pause / next / previous / перемотка).
- **Профиль**: зрелость вкуса, сигналы, топ артистов, ссылки share radio
  (создать / скопировать / поделиться / отозвать), мобильный поток, выход.
- Сессия восстанавливается после перезапуска (`GET /api/now?session_id=`).

Поток по умолчанию запрашивается как `?q=mobile` (AAC/MP3, если сервер уже
перекодировал трек, иначе оригинал). AVPlayer играет MP3, AAC/M4A, ALAC, FLAC,
WAV; трек в неподдерживаемом формате (например, OGG) пропускается с уведомлением.

## Сборка без Mac

Проект описан в [`project.yml`](project.yml) (XcodeGen), а собирает его GitHub
Actions на macOS-раннере — workflow [`ios`](../.github/workflows/ios.yml):

1. Любой push, меняющий `ios/**`, или ручной запуск *Actions → ios → Run workflow*.
2. В завершённом прогоне скачай артефакт **Musik-unsigned-ipa** (zip с
   `Musik-unsigned.ipa` внутри).
3. Тег `ios-vX.Y.Z` дополнительно прикрепляет `.ipa` к GitHub Release.

`.ipa` не подписан — подпись делает sideload-инструмент твоим Apple ID.

## Установка на iPhone с Windows (бесплатный Apple ID)

Через [Sideloadly](https://sideloadly.io):

1. Поставь iTunes и iCloud **с сайта Apple** (не из Microsoft Store), затем Sideloadly.
2. Подключи iPhone по USB, нажми «Доверять этому компьютеру».
3. Перетащи `Musik-unsigned.ipa` в Sideloadly, введи Apple ID → **Start**.
4. На iPhone: *Настройки → Основные → VPN и управление устройством* → доверять
   своему Apple ID. На iOS 16+ ещё включи *Настройки → Конфиденциальность и
   безопасность → Режим разработчика* (потребует перезагрузку).
5. При первом входе разреши доступ к локальной сети.

Ограничения бесплатного аккаунта: подпись живёт **7 дней** (потом переустановить
тем же способом — данные и вход сохраняются; Sideloadly умеет авто-обновление по
Wi-Fi), одновременно не больше 3 таких приложений. Альтернатива — AltStore
(AltServer для Windows) с теми же ограничениями.

## Сервер

```bash
MUSIK_PLAYER_ADDR=0.0.0.0:8787          # доступ с телефона по LAN
MUSIK_API_TOKEN=…                       # вставить в приложение
MUSIK_PUBLIC_BASE_URL=http://<lan-ip>:8787   # абсолютные share-ссылки
```

Приложение разрешает HTTP (ATS) — для LAN и Tailscale это нормально; для доступа
из интернета ставь player за HTTPS.

## Разработка на Mac

```bash
brew install xcodegen
cd ios && xcodegen generate && open Musik.xcodeproj
```

Структура: `Musik/App` (точка входа, AppState), `Musik/Core` (API-клиент,
модели, Keychain, загрузка обложек), `Musik/Playback` (PlayerController на
AVPlayer + MediaPlayer), `Musik/Views` (экраны SwiftUI).
